# Commissioning App

Offline-first boiler commissioning app (Europac coal-fired): plant builder → checklists with
photos → motors & VSD parameters → snag list → handover certificate, synced to OneDrive.

Live app: https://ludvig-botha.github.io/Commissioning-app/

See `CLAUDE.md` for how it is built and `CHANGELOG.md` for versions.
